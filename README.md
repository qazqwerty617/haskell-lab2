# Лабораторна робота №2 (Haskell)

**Тема:** Паралельне обчислення визначеного інтеграла  
**Варіант:** 4  

Обчислення визначеного інтеграла \( J = \int_{A}^{B} f(x)\,dx \) із заданою точністю \( \varepsilon \) за формулою Сімпсона з оцінкою похибки за правилом Рунге:

\[
\frac{|I(2n) - I(n)|}{15} < \varepsilon
\]

Обчислення розпаралелюються за допомогою `Control.Concurrent` (`forkOn`, `MVar`).

---

## Підінтегральні функції

1. \( f(x) = \sin(x) \)
2. \( f(x) = x^2 e^{-x} \)
3. \( f(x) = \frac{1}{1 + x^2} \)
4. \( f(x) = \sqrt{x} \cos^2(x) \ln(1 + x) \)

---

## Компіляція та запуск

```bash
# Компіляція з оптимізацією та підтримкою багатопоточності
ghc -O2 -threaded -rtsopts Integral.hs

# Запуск з використанням усіх доступних ядер
./Integral +RTS -N
```
